Add this to the existing case-detail drawer, without changing the existing visual shell:

import { PrivacyGovernanceDecisionActions } from "./PrivacyGovernanceDecisionActions";

<PrivacyGovernanceDecisionActions
  caseDetail={selectedCase}
  onDecisionCompleted={async (updatedCase) => {
    setSelectedCase(updatedCase);
    await refreshDashboard();
  }}
/>

IMPORTANT:
- selectedCase must contain change_id.
- refreshDashboard must re-fetch summary/status-chart/cases.
- Keep the existing drawer and responsive CSS.
- Do not use GET for state-changing actions.
- Production must replace reviewer/role request-body identity with authenticated
  server-side identity and authorisation.
