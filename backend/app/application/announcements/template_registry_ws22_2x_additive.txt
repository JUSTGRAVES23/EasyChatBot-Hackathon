Add this method to the existing AnnouncementTemplateRegistry:

    def list_templates(self) -> tuple[AnnouncementTemplate, ...]:
        """Return the approved template catalog in deterministic order."""
        return self._repository.list_all()

The repository used by WS-22.2.x must expose:

    def list_all(self) -> tuple[AnnouncementTemplate, ...]:
        ...

For the existing in-memory repository, implement list_all as:

    def list_all(self) -> tuple[AnnouncementTemplate, ...]:
        return tuple(self._items.values())

For a production repository, implement list_all against the authoritative
template store. Do not hard-code templates in the frontend.
