# W15.6 Implementation Boundary

## Existing code that remains stable

Current:
API → SessionIdentityProvider → IdentityProvider → Principal → AuthorizationService → application service

Do not remove this path during contract definition.

## Future insertion point

Preferred conceptual boundary:

External IAM
  ↓
Identity Adapter
  ↓
validated identity + authentication evidence
  ↓
Authentication Assurance Service
  ↓
Principal / Assurance Context
  ↓
Authorization
  ↓
Application Service

Potential names only; no files should be created until review approval:

app/application/identity/authentication_assurance_service.py

## Important

The existing SessionIdentityProvider is not declared obsolete by W15.6.

Migration must be incremental and preserve existing application behavior until the external IAM path has its own passing security/integration suite.
