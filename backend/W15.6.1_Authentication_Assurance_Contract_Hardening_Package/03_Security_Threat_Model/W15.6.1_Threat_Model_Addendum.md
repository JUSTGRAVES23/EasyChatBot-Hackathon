# W15.6.1 Threat Model Addendum

| Threat | Control | Test |
|---|---|---|
| Caller-forged A3 | Only validated adapter evidence enters assurance service | 17 |
| Clock manipulation | Trusted server/application time | 18 |
| Provider audience confusion | Mandatory audience validation | 19 |
| Post-validation mutation | Frozen validated evidence/context | 20 |
| Assurance ordering regression | Explicit numeric ordering | 21 |

Residual risks (transaction authorization, WebAuthn implementation, IAM deployment and production key management) remain outside W15.6.1 and require their own reviews.
