# W15.6.1 Implementation Boundary

## Allowed
- Contract documentation.
- Contract-only reference model.
- Threat-model additions.
- Test strategy.
- Review/sign-off artifacts.

## Forbidden in W15.6.1
- Production source changes.
- IAM dependency installation.
- ZITADEL/Keycloak adapter implementation.
- WebAuthn/passkey implementation.
- MFA implementation.
- Principal redesign.
- SessionIdentityProvider replacement.
- AuthenticationService redesign.
- Transaction authorization.
- Business-service assurance gates.

## Future boundary
```text
External IAM -> Identity Adapter -> Validated Evidence
             -> Authentication Assurance -> Assurance Context
             -> Authorization Policy
                 -> normal application service
                 -> high-risk Transaction Authorization -> business service
```

The existing authentication/session path remains valid during migration.
