# W15.6.1 Test Strategy

Existing W15.6 tests 1–16 remain applicable.

## New hardening tests

### 17 — Caller cannot forge A3
Caller-supplied A3/phishing-resistant/user-verified claims are rejected unless represented by validated adapter evidence.

### 18 — Freshness uses trusted server time
Stale evidence remains stale even if caller supplies a favorable current timestamp.

### 19 — Invalid or missing audience
Provider evidence with missing/invalid audience is rejected before assurance evaluation.

### 20 — Validated evidence is immutable
Attempts to mutate assurance-relevant fields after validation fail.

### 21 — Assurance ordering invariant
Assert `A3 > A2 > A1 > A0` and ensure comparisons are semantic/numeric, not lexical.

## Regression gate
Any relevant failure means:
STOP -> DIAGNOSE -> FIX -> TEST -> REVIEW -> VERIFY

No commit or workstream advancement while relevant tests fail.
