# WS-21.17 — Private Classroom Detail

## Implemented

- `GET /api/operations-center/chat-operations/private-classroom`
- Fresh dependency health probes on every request.
- Current in-process `OperationalEventService` incident/event state.
- Private Classroom filtering.
- Dependency status.
- Operational metrics.
- Incident lifecycle/investigation fields.
- Sanitized operational events.
- No second incident store.
- No persistence redesign.

## Architecture

Browser -> Private Classroom API -> OperationalDashboardService ->
OperationalEventService / OperationalHealthSnapshotService -> current state.

## Important runtime limitation

`OperationalEventService` remains in-memory by design for WS-21.17.
Incidents/events therefore disappear when the backend process restarts.
Persistence is intentionally deferred to a separate workstream.

## Validation

Run from the repository root:

```powershell
pytest backend/tests/operations_center/test_ws21_17_private_classroom_api.py -q
```

Then, with the API running:

```powershell
Invoke-RestMethod `
  "http://localhost:8000/api/operations-center/chat-operations/private-classroom" |
ConvertTo-Json -Depth 12
```

- `generated_at`
