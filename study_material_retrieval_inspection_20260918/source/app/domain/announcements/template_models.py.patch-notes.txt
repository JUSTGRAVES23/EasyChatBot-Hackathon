WS-22.2.x integration note

The existing WS-22.1 AnnouncementTemplate model is extended additively with:
- description: human-readable operator guidance
- category: controlled template grouping

Both fields should have defaults so existing WS-22.1 template construction remains compatible.

The existing AnnouncementTemplateVersion already provides:
- structure
- required_fields
- optional_fields
Those fields are used by the editor to generate the controlled form.

Do not replace the WS-22.1 model wholesale.
