# WS-22.3.2 — Durable Execution & Idempotency

This package is the next hardening slice after WS-22.3.1.

It adds durable execution state behind an application repository port and
keeps the publisher provider/channel-independent.

The SQLAlchemy adapter is intentionally session-factory injected so it can be
wired into the existing EasyChatBot persistence architecture.
