# Head Engineer Handoff

This ZIP intentionally contains the W15.1 engineering specification and
acceptance package rather than an unverified bulk overwrite of the repository.

Reason: the current inspection confirms the lifecycle defect, but the safest
implementation requires preserving the exact existing UoW interface and
constructor semantics. The repository itself is the source of truth.

The change is narrowly scoped to:
- application UoW factory contract;
- DeveloperAdminService dependency/lifecycle;
- PostgreSQL composition;
- transaction-bound audit repository lifecycle;
- lifecycle/concurrency tests.

Do not modify:
- Alembic migrations;
- unrelated authentication flows;
- RBAC definitions;
- frontend;
- Telegram;
- provider/runtime architecture.

STOP conditions:
- any existing relevant test regresses;
- a factory still returns a shared mutable UoW;
- audit and role mutation use different transactions;
- production composition retains a singleton mutable UoW;
- security authorization is weakened.

After implementation, require targeted tests, full backend regression, security
review, and 4-eyes sign-off before marking Phase 1 production-ready.
