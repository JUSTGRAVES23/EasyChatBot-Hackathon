# Governance Center UI contract

The page intentionally has one prominent YETI artwork instance.

YETI is not an operational actor.

UI flow:

Hero
  -> YETI identity
  -> governance health

YETI Governance Brief
  -> explanation

Governance Status
  -> YETI explanation

Provider Controls
  -> YETI explanation

Cybersecurity Governance
  -> YETI explanation

Governance Events
  -> YETI interpretation

Audit Evidence
  -> human-authority reminder

The backend remains authoritative.
