# Frontend acceptance checklist

- Home renders on desktop.
- Home renders on 390px-ish iPhone viewport.
- Start Exploring opens Chat.
- Suggested prompt populates the composer.
- Enter sends a question.
- `/api/cinema` is called.
- Loading state is visible.
- Backend error is visible and retryable.
- Successful result renders.
- Sources are clickable.
- Save changes the Academy state.
- Learning Challenge is reachable.
- Challenge accepts text and produces a visible feedback state.
- Academy and Profile navigation works.
- Mobile bottom navigation works.
- No API secret appears in browser/client code.
