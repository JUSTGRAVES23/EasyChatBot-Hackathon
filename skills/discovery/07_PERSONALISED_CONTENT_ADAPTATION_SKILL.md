# Skill: Personalised Content Adaptation

**Skill ID:** discovery.personalised_content_adaptation
**Version:** 1.0
**Status:** Proposed / Beta 1

## Purpose

Transform discovered content into a useful learner experience without changing the underlying source content.

Examples:

- Podcast → vocabulary challenge
- News article → B2 explanation
- Product/topic → educational context
- Current event → language-learning activity

## Activate when

The learner asks to learn from or interact with discovered content.

## Inputs

- Selected content
- Source metadata
- Learner language/learning context
- Learning objective
- Approved learner preferences

## Workflow

1. Confirm the selected source.
2. Determine the learner's learning objective.
3. Identify useful content segments.
4. Adapt difficulty and presentation.
5. Generate an optional learning activity.
6. Preserve factual meaning.
7. Clearly distinguish source information from generated teaching material.

## Decision rules

- Do not alter or misrepresent source facts.
- Do not fabricate quotations or transcript content.
- Adapt presentation, not factual source claims.
- Keep the original source reference available.

## Output

A personalised learning representation linked to the discovered content.

## Success metrics

- Learning usefulness
- Comprehension improvement
- Learner engagement
- Source-fidelity accuracy
