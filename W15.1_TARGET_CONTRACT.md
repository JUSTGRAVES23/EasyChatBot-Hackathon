# Target Contract

The preferred application boundary is conceptually:

    class DeveloperAdminUnitOfWorkFactory(Protocol):
        def create(self) -> DeveloperAdminUnitOfWork:
            ...

The exact spelling can follow existing project conventions.

Production service composition:

    DeveloperAdminService(
        repository=auth_repository,
        unit_of_work_factory=developer_admin_uow_factory,
        audit_service=developer_admin_audit_service,
    )

Mutation:

    uow = self._unit_of_work_factory.create()
    async with uow:
        ...

Factory:

    def create_developer_admin_uow():
        audit_repository = PostgreSQLDeveloperAdminAuditRepository(
            auth_session_factory
        )
        return PostgreSQLDeveloperAdminUnitOfWork(
            auth_session_factory,
            audit_repository=audit_repository,
        )

Do not copy this mechanically if the existing UoW constructor already provides a
better transaction-bound composition mechanism. Preserve the established
contracts and make the smallest safe change.
