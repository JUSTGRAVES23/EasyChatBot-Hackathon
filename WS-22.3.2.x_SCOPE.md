# WS-22.3.2.x — Persistence Integration

## Objective

Move the already-existing WS-22 durable publication-execution repository onto
the canonical EasyChatBot SQLAlchemy metadata and add the missing Alembic
schema migration.

## Explicit non-scope

- No deletion of `announcement_operations` execution code.
- No WS-21 changes.
- No Telegram integration.
- No frontend changes.
- No publication-content migration.
- No learner/conversation data changes.

## Acceptance criteria

- Execution model subclasses the existing `Base`.
- No second DeclarativeBase remains in this repository.
- Existing table name is preserved.
- Alembic migration is chained from `8659a97d744b`.
- Migration creates only `announcement_publication_executions`.
- Idempotency key remains unique through the primary key.
- Operational execution fields persist.
- Sensitive content is excluded.
- Existing announcement tests remain green.
- Migration can be reviewed independently before applying.

## Architectural note

The older `backend.app.application.announcement_operations` execution
implementation is intentionally preserved in this slice because repository
inspection confirmed that tests still import it. Consolidation, if desired,
must be a separate refactoring workstream after dependency analysis.
