# WS-02 Implementation Gate

Before integration:

- [ ] Channel exists.
- [ ] Channel name and branding approved.
- [ ] Administrator ownership confirmed.
- [ ] Bot is NOT channel administrator.
- [ ] Channel description contains application link.
- [ ] Channel description contains issue-report link.
- [ ] Reactions configured.
- [ ] Five initial messages approved.
- [ ] Initial messages published chronologically.
- [ ] Relevant onboarding messages pinned.
- [ ] Publishing kill switch tested.
- [ ] Telegram publisher tested with a fake client.
- [ ] No production token committed.
- [ ] Publication audit record verified.
- [ ] Manual publication flow demonstrated.
- [ ] No autonomous publisher enabled.
