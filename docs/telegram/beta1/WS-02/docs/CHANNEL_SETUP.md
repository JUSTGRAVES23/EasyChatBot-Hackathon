# Channel Setup — Beta 1

## Surface

Create one Telegram channel:

**EasyChatBot Academy**

The administrator is the sole publisher.

## Bot role

The classroom bot is NOT an administrator of this channel.

The bot continues to operate the private classroom only.

## Reactions

Enable reactions appropriate to learning and service communication, such as:

- ❤️
- 📚
- 🎙️
- 👍
- 🐛
- 🙏

Keep the reaction set useful and avoid excessive choices.

## Description

Recommended description:

> 🌱 EasyWorld — Growing with You
>
> Official EasyChatBot Academy Beta 1 announcements, maintenance updates,
> known issues, important instructions and Beta testing information.
>
> 🎓 Open EasyChatBot Academy: {APP_URL}
>
> 🆘 Report a problem: {ISSUE_URL}

The actual URLs must be supplied through controlled configuration.

## Historical onboarding

Publish the initial onboarding messages in chronological order. A later
joining learner should be able to understand the Beta without needing a
private administrator explanation.
