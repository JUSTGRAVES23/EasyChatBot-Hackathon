# WS-02 Roadmap

## Beta 1

### Phase 1 — Foundation
- configuration
- announcement types
- policy
- formatter

### Phase 2 — Controlled publication
- Telegram publisher adapter
- publishing kill switch
- publication record

### Phase 3 — Channel onboarding
- description
- initial five-message history
- pins
- reactions

### Phase 4 — Verification
- unit tests
- publisher integration test with fake Telegram client
- smoke publication using the controlled production procedure

## Beta 2 candidates

Only after Beta 1 demonstrates a stable need:
- announcement repository
- scheduled publication
- approval workflow
- CMS
- analytics
- survey integration
- automated maintenance/outage notifications

Do not implement these in Beta 1.
