# ADR-002 — One Bot and One Announcement Channel

## Decision
Beta 1 uses exactly:
1. one private classroom bot;
2. one private announcement channel.

## Rationale
This provides sufficient separation between private learning interaction and official communication without creating unnecessary Telegram groups.

## Channel control
Only the administrator publishes.
The bot does not administer the channel.

## Future
Additional surfaces can be evaluated for Beta 2 based on actual Beta evidence.
