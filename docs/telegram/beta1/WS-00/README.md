# WS-00 — Telegram Beta 1 Architecture & Contracts

## Objective
Freeze the architecture and contracts for the EasyChatBot Telegram Beta 1 workstream before implementation begins.

## Beta 1 scope
- One private classroom Telegram bot.
- One private announcement channel.
- Approved Beta users only for the private classroom.
- French and Spanish Worlds only.
- World onboarding occurs in the EasyChatBot web application.
- Telegram is a thin adapter.
- Issue reporting opens the EasyChatBot web application.
- Feedback/survey implementation is deferred.

## Explicit exclusions
- No Telegram World administration.
- No /change_world, /select_world, /join_world, /switch_world, /add_world.
- No announcement CMS.
- No multiple Telegram groups per World.
- No sophisticated survey/campaign platform.
- No autonomous official announcement publishing.

## Status
Architecture package for stakeholder review. No production code is included intentionally.
