# GDPR and AI Governance Checklist

## Governance

- Record of Processing Activities
- Data Protection Impact Assessment
- Data retention policy
- Data subject rights process
- Processor agreements
- International transfer assessment

## AI Systems

- AI transparency information
- human oversight
- prompt/data governance
- training data governance
- logging controls
- model risk assessment

## Learning Platform

- learner consent choices
- memory controls
- explainable personalization
- ability to disable memory features
- separation between tutoring and profiling

## Social Platform

- moderation governance
- illegal content escalation
- user safety controls
- recommender system governance
