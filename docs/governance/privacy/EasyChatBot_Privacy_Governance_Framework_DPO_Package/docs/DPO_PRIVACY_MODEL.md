# DPO Privacy Model

## 1. Data separation

Identity Layer:
- account identifiers
- authentication identifiers
- payment identifiers
- security information

Operational Layer:
- conversations
- moderation events
- platform interactions

Learning Intelligence Layer:
- learning progress
- mistakes
- preferences
- teaching effectiveness

The Learning Intelligence Layer should consume pseudonymised data.

## 2. User identification

Allowed:
- controlled identity access for security, abuse prevention and legal obligations

Not allowed:
- uncontrolled linking of learning analytics to real identity

## 3. Social platform considerations

Controls:
- user reporting
- moderation workflow
- abuse prevention
- safety investigations
- transparency mechanisms
- retention controls
