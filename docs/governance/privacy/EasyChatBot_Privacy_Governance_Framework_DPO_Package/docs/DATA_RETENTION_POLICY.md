# Data Retention Policy

Categories:

## Account Data
Retention:
Required by account lifecycle and legal obligations.

## Conversation Events
Purpose:
- service delivery
- quality improvement
- future Memory Engine processing

Controls:
- pseudonymisation
- retention limitation
- access control

## Learning Memories

Must have:
- user visibility
- deletion capability
- export capability
- explainability

## Security Logs

Separate retention based on:
- security monitoring
- fraud prevention
- legal requirements
