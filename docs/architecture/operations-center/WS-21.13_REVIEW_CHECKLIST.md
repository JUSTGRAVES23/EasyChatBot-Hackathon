# WS-21.13 — Senior Review Checklist

## Architecture

- [ ] Existing Operations Center remains canonical.
- [ ] No second route introduced.
- [ ] No second API namespace introduced.
- [ ] Frontend does not access infrastructure directly.
- [ ] Runtime boundaries remain intact.

## Security

- [ ] Dashboard data is sanitized.
- [ ] No credentials/secrets.
- [ ] No learner content.
- [ ] User references are authorization-controlled.
- [ ] Correlation IDs are safe to expose.

## Maintainability

- [ ] Existing components are reused.
- [ ] No unnecessary abstractions.
- [ ] Data mapping is explicit.
- [ ] Missing data is represented explicitly.
- [ ] No speculative backend fields.

## UX

- [ ] Operator can identify system health quickly.
- [ ] Failures are visually obvious.
- [ ] Private Classroom and Announcement Group are distinct.
- [ ] Investigation metadata is accessible.
- [ ] Responsive layouts are usable.

## Release gate

Do not proceed to WS-21.14 if:

- frontend type-check fails
- build fails
- required dashboard fields are invented
- secrets/content can reach the UI
- operational surfaces are mixed
- existing Operations Center functionality regresses
