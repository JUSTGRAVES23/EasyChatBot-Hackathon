# WS-21.12 Integration Contract

## Canonical endpoints

Frontend:

`/operations-center`

Backend:

`/api/operations-center/*`

The integration must use the existing Operations Center API client rather than introducing direct browser calls to infrastructure dependencies.

## Canonical snapshot concepts

The integration should expose, as available from the existing backend contract:

- overall health
- dependency health
- private classroom metrics
- announcement group metrics
- operational incidents
- correlation IDs
- controlled user references
- World association
- operational timeline

If a field is not currently provided by the backend, the frontend must not invent it. The backend contract must be extended first.

## Failure behavior

The UI must distinguish:

- loading
- healthy data
- degraded/partial data
- backend unavailable
- unauthorized data

Internal exceptions must not be rendered directly to operators.

## Read-only rule

The dashboard observes operational state. It does not:

- execute LLM providers
- modify PostgreSQL
- modify Telegram
- publish announcements
- remediate incidents
- change runtime policies
