# WS-21.14 — Rollback Strategy

If real backend wiring causes regression:

1. Stop the integration.
2. Do not weaken the backend contract.
3. Do not add mock production data.
4. Revert only the WS-21.14 integration changes.
5. Keep WS-21.11 visual components intact.
6. Restore the last known working `/operations-center` behavior.
7. Record the contract or implementation defect.
8. Add a regression test.
9. Re-run the complete validation suite.
10. Resume only after review.

The Operations Center must never remain in a knowingly broken state.
