# WS-21.15 — End-to-End Operations Center Verification

## Objective

Verify the complete Operations Center path from the browser through the canonical API and application services to the operational health/event/incident data, and back to the operator-facing dashboard.

WS-21.15 is the final verification gate for the WS-21 Operations Center sequence.

It does not introduce new dashboard functionality.

## End-to-end path

```text
Operator browser
      |
      v
/operations-center
      |
      v
Existing operationsCenter API client
      |
      v
FastAPI Operations Center API
      |
      v
Application dashboard service
      |
      +--> health services
      +--> dependency probes
      +--> operational events
      +--> operational incidents
      |
      v
Sanitized operational snapshot
      |
      v
Operations Center UI
```

## Verification principle

Test the complete capability, not only individual functions.

The result must demonstrate:

- real operational data reaches the dashboard
- dependency failures are visible but sanitized
- investigation metadata remains controlled
- Private Classroom and Announcement Group remain separate
- no learner content or secrets reach the UI
- existing Operations Center functionality remains intact
