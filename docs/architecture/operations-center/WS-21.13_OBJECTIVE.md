# WS-21.13 — Operations Center UX & Data Contract Validation

## Objective

Validate the WS-21.11 Operations Center visual design against the existing frontend and backend contracts before real production wiring is enabled.

This workstream is validation-first. It must not introduce a second dashboard, route, port, API namespace, or direct infrastructure access from the browser.

## Scope

- Existing `/operations-center` route
- Existing Operations Center API client
- Existing `/api/operations-center/*` contract
- WS-21.8 operational snapshot
- WS-21.9 events/incidents
- WS-21.10 dashboard contract
- WS-21.11 visual components

## Explicit non-goals

- Do not replace the existing Operations Center shell.
- Do not delete duplicate implementations.
- Do not activate WS-21.12 production wiring.
- Do not create another Operations Center route.
- Do not create another backend API.
- Do not add direct browser calls to PostgreSQL, Telegram, Ollama, OpenAI, or other infrastructure.
