# WS-21.13 Security Rules

The Operations Center is an operational observability surface.

## Never render

- learner message text
- learner prompts
- model responses
- API keys
- bot tokens
- database URLs
- passwords
- authorization headers
- raw provider credentials

## Identity

Telegram identity may only be represented by a controlled operational reference supplied by an authorized backend service.

The dashboard must not derive or expose unrestricted Telegram identifiers from arbitrary event payloads.

## Correlation

Correlation IDs are permitted because they support operational investigation.

They must not contain secrets or message content.

## Failure responses

Backend exceptions must be mapped to safe operator-facing states.

Never render:

```text
exception.message
traceback
database connection string
provider error containing credentials
```

directly in the browser.

## Architecture rule

The browser observes sanitized operational data.

It never probes infrastructure directly.
