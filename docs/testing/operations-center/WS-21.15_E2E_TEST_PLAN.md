# WS-21.15 — End-to-End Test Plan

## 1. Happy path

Given all critical dependencies are healthy:

- [ ] `/operations-center` loads.
- [ ] Overall health is healthy.
- [ ] PostgreSQL is shown healthy.
- [ ] LLM provider is shown healthy.
- [ ] Telegram is shown healthy.
- [ ] Private Classroom metrics appear.
- [ ] Announcement Group metrics appear separately.
- [ ] Incidents appear when present.
- [ ] World information appears when present.
- [ ] Correlation IDs appear when present.

## 2. PostgreSQL failure

Simulate a PostgreSQL dependency failure.

Verify:

- [ ] dashboard remains usable
- [ ] PostgreSQL becomes unhealthy/degraded
- [ ] overall health reflects the failure
- [ ] other dependency results remain visible
- [ ] no connection string is displayed
- [ ] no password is displayed
- [ ] no traceback reaches the browser

## 3. LLM provider failure

Verify:

- [ ] LLM status changes
- [ ] overall health reflects the failure
- [ ] PostgreSQL and Telegram results remain visible
- [ ] provider credentials are never exposed
- [ ] safe error state is rendered

## 4. Telegram failure

Verify:

- [ ] Telegram status changes
- [ ] affected operational surface can be identified
- [ ] Private Classroom and Announcement Group remain separate
- [ ] bot token is never exposed
- [ ] internal Telegram exception details are sanitized

## 5. Private Classroom incident

Create a controlled operational event containing:

- event type
- correlation ID
- World
- controlled user reference
- operational outcome

Verify:

- [ ] incident appears
- [ ] correlation ID appears
- [ ] World appears
- [ ] controlled user reference appears only when authorized
- [ ] learner message content does not appear

## 6. Rate-limit event

Verify:

- [ ] rate-limit count increments
- [ ] Private Classroom remains the affected surface
- [ ] no learner message content is displayed

## 7. Abuse event

Verify:

- [ ] abuse count increments
- [ ] affected surface remains identifiable

- [ ] content is not exposed

## 8. Message failure

Verify:

- [ ] failure metric increments
- [ ] incident/event can be correlated
- [ ] no learner message content is exposed

## 9. Announcement Group event

Verify:

- [ ] announcement metrics remain separate from Private Classroom
- [ ] scheduling/delivery/failure information is visible

## 10. Backend unavailable

Simulate API/backend unavailability.

Verify:

- [ ] dashboard does not crash
- [ ] safe operator-facing error state appears
- [ ] internal exception details are not displayed
- [ ] retry/reload behavior remains understandable
