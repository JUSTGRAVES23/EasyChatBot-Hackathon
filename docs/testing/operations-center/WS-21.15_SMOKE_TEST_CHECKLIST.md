# WS-21.15 — Production Smoke Test

## Before starting

- [ ] Backend running in intended environment
- [ ] Frontend running in intended environment
- [ ] Required environment configuration present
- [ ] No secrets printed to terminal/output

## Operator smoke test

1. Open `/operations-center`.
2. Confirm the page loads.
3. Confirm overall health is visible.
4. Confirm PostgreSQL status is visible.
5. Confirm LLM status is visible.
6. Confirm Telegram status is visible.
7. Confirm Private Classroom section is visible.
8. Confirm Announcement Group section is visible.
9. Confirm incident section is visible.
10. Confirm World section is visible.
11. Confirm timeline is visible.
12. Trigger a controlled test event.
13. Confirm event appears.
14. Confirm correlation ID can be followed.
15. Confirm no learner content is displayed.
16. Confirm no secret is displayed.
17. Trigger a controlled dependency failure.
18. Confirm degraded/unhealthy state.
19. Restore dependency.
20. Confirm recovery.

## Pass criteria

The dashboard must remain understandable throughout the failure/recovery cycle.
